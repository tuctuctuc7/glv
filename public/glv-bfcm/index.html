Metric definitions & scope

Spend: ad spend in CZK. Purchases: attributed purchases. ROAS: purchase revenue ÷ spend.

CTR: all clicks ÷ impressions × 100. CPM: spend ÷ impressions × 1,000. Cost / LPV: spend ÷ landing-page views. CVR: purchases ÷ landing-page views × 100.

Concepts combine matching CC / PAC / AI EGC codes from ad names across campaigns; an unambiguous ad-set code is a fallback only. CC13A/B ad sets with CC13 ads therefore roll up to CC13. AI EGC plus the first number defines its concept: AI-EGC_01_01 and AI-EGC_01_04 both belong to AI EGC 01, including Shared and Private variants. Animated banners are grouped together as Animated banners across CC codes. Ads without a code remain Unmapped. All views sum absolute metrics before recalculating ratios; undefined ratios display —. Campaigns includes zero-delivery campaign inventory. Filters apply to both totals and table. Search matches concept or campaign before aggregation.

Scope: BFCM Promo only — campaign names must contain the Promo-BFCM token (spaces, underscores or hyphens allowed). Default: 25 Nov 2026 through the current Europe/Prague day. Select an inclusive From/To range; Campaign to date restores the automatically advancing end. Daily breakdown shows chronological daily subrows and calculates parent metrics from those same daily facts. No-delivery days show zero absolutes and unavailable ratios. All metrics and views use the selected range; account attribution setting, impression-time reporting. The inclusive range and snapshot time are shown above; attribution can change after delivery. Manual Refresh requests current Meta data only when the displayed snapshot is more than 10 minutes old; the API separately allows up to 60 seconds of server reuse.
